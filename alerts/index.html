In the bot: /webhook https://your-url. The bot answers with a secret; every signal for your tokens is then POSTed to that URL, signed with it. /webhook test sends a test. Only https:// on a public address is accepted.

Headers

x-agz-event · x-agz-id (same signal → same id: ignore duplicates) · x-agz-timestamp · x-agz-signature: sha256=HEX where HEX = HMAC-SHA256(secret, timestamp + "." + raw body). Reject it if the signature does not match or the timestamp is more than 5 minutes old.

Auto-trade platforms that want their own format

    
Platforms such as 3Commas, WunderTrading or Cornix give you a webhook URL plus the JSON they expect. Copy that JSON from the platform, swap the values for placeholders and save one template per event — then only those events are sent, in that format. Check the platform's own docs for its exact fields; the line below is only an example.

    
/template setup {"pair":"{{base}}_USDT","side":"{{buy_sell}}","order_type":"limit","price":{{entry}},"stop_loss":{{stop_loss}},"take_profit":{{tp2}}}
/template exit  {"pair":"{{base}}_USDT","action":"close"}

    
Placeholders: {{event}} {{action}} {{symbol}} {{base}} {{side}} {{buy_sell}} {{close_side}} {{price}} {{entry}} {{stop_loss}} {{tp1}} {{tp2}} {{close_pct}} {{valid_until}} {{reason}} {{net_bp}} {{id}} {{time}}. /template lists yours; /template setup off removes one.

    

      
Verify the signature — Node.js
import { createHmac, timingSafeEqual } from 'node:crypto';
// raw = the request body exactly as received (a string)
function verify(headers, raw, secret) {
  const ts = headers['x-agz-timestamp'];
  if (Math.abs(Date.now() / 1000 - ts) > 300) return false;
  const want = 'sha256=' + createHmac('sha256', secret)
    .update(ts + '.' + raw).digest('hex');
  const got = headers['x-agz-signature'] || '';
  return got.length === want.length &&
    timingSafeEqual(Buffer.from(got), Buffer.from(want));
}

      
Verify the signature — Python
import hmac, hashlib, time
# raw = request body bytes exactly as received
def verify(headers, raw: bytes, secret: str) -> bool:
    ts = headers["x-agz-timestamp"]
    if abs(time.time() - int(ts)) > 300:
        return False
    want = "sha256=" + hmac.new(secret.encode(),
        ts.encode() + b"." + raw, hashlib.sha256).hexdigest()
    return hmac.compare_digest(
        headers.get("x-agz-signature", ""), want)
