Leads, not verified programs. Posts and news that mention a bug bounty launch. X/Twitter has no free API and the public mirrors (Nitter, xcancel) are down, so X is covered by Claude's deep scan: it searches x.com posts, then checks every program on its official page before it lands in the Programs tab. Unverified X finds show up here as "Claude · X".
The VPS scanner hits these sources every few hours; this page shows the latest encrypted snapshot it published. Release dates come from the platform's own field where one exists (HackerOne launched_at, Intigriti createdAt, Immunefi launchDate, …). Bugcrowd and YesWeHack don't publish one, so the radar estimates it from the history of bounty-targets-data snapshots (marked ≈) and from its own first-seen date. Scope comes from the same dataset where the platform API doesn't include it.
Data is cached from public listings — always confirm scope, rewards and rules on the program's own page before testing. Only test what a program explicitly puts in scope.
